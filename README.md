# 离火长明 · Q版长离 Live2D 桌宠

Windows x64 桌面伴侣，当前工程版 **0.7.9 / 原生模型 v71**。采用 Tauri、React、TypeScript 与 Live2D Cubism SDK。

<img src="public/models/changli/preview.jpg" alt="长离桌宠预览" width="320" />

## 使用

下载[当前0.7.9便携EXE或安装包](https://github.com/HABAI182/changli-companion/releases/tag/v0.7.9)，程序无需开发服务器。右键角色打开互动菜单和设置；拖动键位于键盘右下角。历史版本分别留档，见文末版本索引。

- 键盘都由长离左手按压，按左右/前后四区移动，前后幅度较小；空格单独落点，右手与鼠标本体、线缆联动。
- 大头弹性回摆，发饰随动，凤凰翅膀、尾羽和火苗持续动态；可选完整、轻柔或关闭动态。
- 17个可用表情、3段小动作、36条互动气泡、50%—200%连续大小调节。
- Windows透明置顶、托盘、鼠标穿透与恢复快捷键、全屏避让、边缘磁吸、3个常用位置。

0.7.9使用用户上传的完整原图作为图标，设置改为外观/互动/桌面/高级四分页；新增系统/深浅主题、强调色、布局密度、视线跟随、弹性与键鼠幅度、气泡时长及空闲频率。设置窗口置顶并聚焦，保存后保持在桌宠前面；高级页的GitHub更新按钮打开私有版本下载页，项目主页按钮打开仓库，未加入自动下载安装。0.7.8将鼠标重建为完整底层，手掌和袖口分前后绘制；袖口底层随大头变形，键盘手上方下颌沿用原脸纹理并柔化接缝，图标采用参照桌宠原图生成的长离头像。0.7.7修复鼠标手左侧前景残留，并补全键盘手移开后露出的下颌缺角；补片随原生脸部变形。0.7.6将生气火苗移到头部外缘、放大并加轮廓，改善小尺寸识别。0.7.5将开心改为睁眼微笑，困倦使用闭眼、大小递减的zzz和少量口水。移除打招呼、入睡两项动作与过期快捷键目标；保留凤凰互动、生气冒火和害羞。生气新增随脸运动的火苗。气泡随桌宠等比缩放、去掉末尾句号，边框加粗。靠近淡化默认关闭。应用和托盘共用珊瑚粉发色、白发尾、金色发饰的简约长离头像图标。

设置增加按程序文件名指定的全屏避让例外，小动作菜单改为双列。保留手部轮廓修整、左尾羽加长22%、大头弹性和凤凰动态。

## 开发

Windows需要Node.js、Rust、Microsoft C++ Build Tools / Windows SDK与WebView2。

```powershell
npm ci
npm run desktop
```

浏览器预览：`npm run dev`。检查：`npm run typecheck`、`npm test`。Windows打包：`npm run package:windows`。

浏览器只能预览角色和交互；全局输入、透明桌面窗口、托盘、磁吸与全屏避让需要运行Windows程序。
