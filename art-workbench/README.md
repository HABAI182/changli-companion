# 长离美术工作区

`front-hair-candidate.png` 与 `phoenix-candidate.png` 是从当前透明预览图生成的**前发、小凤凰分层候选稿**，仅供画师评估与手工修正，未接入产品，也不是 Live2D 模型。生成稿与原图定位、轮廓仍有差异，尤其凤凰被放大并偏移，不能直接用于绑定。

真正 Cubism 模型需要前发、后发、脸部、眼睛、服装、双手、键鼠和小凤凰等彼此独立且可补全遮挡区域的原画图层，在 Cubism Editor 中建 ArtMesh、参数、变形器和动作，再导出 `.model3.json`、`.moc3`、贴图及动作文件。角色形象以用户参考图为准，动作节奏和细节质量参考宇痕冫的桌宠体验，不复制其模型或贴图。
