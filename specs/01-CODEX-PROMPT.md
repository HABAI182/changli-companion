# 开发提示词：离火长明

请直接在当前工作目录实现《离火长明——Q版长离桌面伴侣》的首个可运行版本。先检查现有代码、AGENTS.md 和开发环境，保留已有用户改动。完成实现、运行验证和使用文档，不要只返回方案。用中文沟通。一般实现选择由你决定；缺少美术素材时先完成其余功能，并明确素材缺口。

## 产品与优先级

这是一款 Windows 10/11 桌面宠物。角色固定为《鸣潮》的长离，采用 Q 版半身、坐在桌前的 BongoCat 式构图。最重要的体验是：用户在其他软件打字、移动鼠标时，长离同步动作；空闲时眨眼、呼吸、喝茶。其次是专注计时与今日待办。

美术风格参考宇痕冫的桌宠展示，角色细节以长离官方图片/PV为准。阅读同目录的 02-ART-DIRECTION.md 和 03-REFERENCES.md。不要把普通红发女孩、猫或表情符号当成长离成品。

## 首版必须实现

### 1. 桌宠窗口

- 默认约 360×320 逻辑像素、透明背景、无边框，位于主屏幕右下角工作区内。
- 可拖动、缩放，支持置顶、隐藏、显示和鼠标穿透；记住位置和尺寸。
- 提供系统托盘菜单：显示/隐藏、设置、关闭穿透、退出。穿透开启后仍有可靠恢复入口；配置全局快捷键作为补充，并处理快捷键冲突。
- 桌宠平时不抢焦点。待办和设置在可交互面板或独立窗口中编辑，保证中文输入法可用。
- 多显示器、125%/150%缩放时不失控；显示器移除或位置失效后能回到可见工作区。
- 开机启动为用户可选项，默认关闭。

### 2. 动作与表情

实现一个明确的角色状态机和配置化事件映射，至少包含：

| 触发 | 表现 |
| --- | --- |
| 待机 | 呼吸、眨眼、发梢轻动 |
| 普通按键 | 双手交替敲键盘 |
| 快速连续输入 | 动作加快，少量火羽特效 |
| Enter | 盖章一次 |
| Backspace | 短暂思考表情 |
| 鼠标移动 | 视线轻微跟随，角度限幅 |
| 鼠标左/右键 | 对应手部动作 |
| 滚轮 | 卷轴轻动 |
| 空闲60秒 | 喝茶，随后恢复待机 |
| 空闲180秒 | 闭目休息；新输入唤醒 |
| 点击角色头部 | 微笑/轻微脸红，设置冷却 |
| 完成专注或待办 | 短暂庆祝、火羽消散 |

首版表情目标：默认、微笑、思考、惊讶、无奈、脸红、困倦、认真。素材不足时要区分“已接入动作逻辑”和“已有对应精细美术”，不要把整张图上下移动说成完整手部动画。

动作要有优先级、冷却、过渡和恢复逻辑，避免高速输入不断重启动画、喝茶覆盖敲键盘、暂停后动作卡住。全局监听不得拦截或改变原按键行为。

### 3. 长明专注

- 点击灯具打开计时面板；支持25/45/60分钟、自定义时长、开始、暂停、继续、取消。
- 灯光随进度变化，完成后庆祝，并记录当天已完成的专注分钟数。
- 使用时间戳计算进度，避免后台节流导致计时漂移；系统休眠期间按经过时间计算。完成事件只能结算一次。
- 取消不增加已完成专注统计；暂停时间不计入专注；重启能恢复进行中的会话或给出明确恢复选择。
- 不把键盘次数当成效率评价，不监控或评价用户打开的软件。

### 4. 今日待办卷轴

- 可新增、编辑、完成、删除待办，并选一项为“今日要务”。
- 桌面卷轴展示今日要务，长文本安全截断，展开后可看完整内容。
- 完成时播放盖章动画；支持撤销完成，防止误点。
- 待办、设置、专注记录持久化到本地；跨日统计按本地日期处理。

### 5. 设置与资源

- 提供大小、置顶、穿透、动效强度、帧率和开机启动选项。
- 软件离线可用，无需登录或云端服务。首版无AI聊天、语音克隆、付费商城、面捕和手柄支持；这些只记入后续计划。
- 不保存、上传或在日志中输出用户输入文本、原始按键序列。原生层将事件转换为动画所需的语义信号；普通字符不要拼接成文本。
- 避免在用户编辑软件自己的输入框时触发盖章等干扰动作。

## 技术与结构

新项目优先使用 Tauri 2 + React + TypeScript + Vite，Rust 负责原生能力。已有可用项目则优先沿用结构。新依赖先检查官方文档、兼容性和许可，锁定版本并提交锁文件。

角色首版可用分层透明图片或序列帧渲染；通过统一 Renderer 接口预留 Live2D 适配，但不要伪造 .moc3 模型，也不要为了不存在的模型强行引入完整SDK。设置/记录使用 SQLite 或项目已有的可靠本地存储，说明选择。

输入监听、角色状态机、渲染器、专注逻辑、本地存储、窗口管理分别组织。动画配置与图片资源分离，换模型时不应重写业务逻辑。

全局键鼠监听必须在原生层实现或使用适合的原生库。浏览器 keydown 只能覆盖当前页面；全局快捷键插件也不等于普通键盘监听。输入只用于反馈，不注入其他程序，不要求关闭系统防护；高权限窗口或受保护应用的限制要如实记录。

提供两种运行入口：

1. 浏览器预览：方便查看角色、表情、待办、计时；原生能力明确标为不可用，测试事件面板只在开发模式显示。
2. Windows桌面应用：实现透明置顶、托盘、穿透、原生输入与本地存储，作为正式验收对象。

如果环境缺少 Rust、C++ Build Tools 或 WebView2，先完成可运行预览、原生代码与检查结果，列出缺失依赖及准确命令；不得把仅验证网页说成桌面版已完成。
